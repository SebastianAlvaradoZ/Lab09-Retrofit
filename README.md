# Laboratorio 09: Consumo de API con Retrofit

Aplicación Android (Kotlin + Jetpack Compose) que consume la API
https://json-placeholder.mock.beeceptor.com/ usando Retrofit y Gson.

## Contenido
- Lista de posts (`/posts`) y detalle de un post (`/posts/{id}`)
- Navegación con Navigation Compose (Inicio / Posts)
